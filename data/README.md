# data/

Holds public, de-identified, and/or derived data that allow examples and downstream scripts to run without exposing sensitive information.

## Typical contents
- `*.csv` / `*.tsv` — tidy inputs for Step 2/3.
- `dictionary_*.*` — variable dictionaries or codebooks.
- `derived_*.*` — outputs from Step 1/1b.

Not included: raw or sensitive data.
